# 2026-11-05 AI 测试版本

- Web/API分别使用 `feat/deepseek-ai-test`，契约版本1。
- 入口：账本页“财务AI测试”或 `/ai`，沿用登录守卫和AES请求包装。
- 界面为连续聊天：底部输入框、左右消息、新对话、等待与失败重试；不再提供查询/草稿两个标签。草稿和查询依据均作为聊天内组件。
- 草稿支持卡片内展开修改金额/日期/分类/账户/支付方式/备注、核对完成、取消。服务器版本冲突时刷新并要求重新核对，不静默覆盖；核对不入账、取消不可编辑、15分钟过期。
- 多轮使用API生成的conversationId，客户端不上传模型历史。聊天仅在本页内存，离开/刷新清除；新对话重置数据外发同意。
- Web收到契约版本不匹配、正式写入开启或缺少只读标记时拒绝展示。
- `npm run test:ai`：跨仓库真实HTTP响应与实际Web校验函数验证，3/3通过，包含chat/修改/核对/追问/取消；`npm run build`成功。
- 浏览器验证32元午饭草稿改为35元和现金账户，核对后追问仍读到35元；取消及连续查询正常。375px无横向溢出、输入框保持在底部。聊天版截图 [ai-chat-test-2026-11-05.jpg](ai-chat-test-2026-11-05.jpg)。旧截图仅为首版记录。
- 测试仅用合成数据，未调用真实DeepSeek或MySQL。沙盒不代表生产认证/金融规则已全部验证。

## 启动

```powershell
# API目录
npm run ai:sandbox

# Web目录，另开终端
$env:VITE_API_BASE_URL='http://127.0.0.1:8866'
npm run dev -- --host 127.0.0.1 --port 5176 --strictPort
```

访问 `http://127.0.0.1:5176/ai`。停止后移除本终端环境覆盖再恢复普通联调。

真实配置和数据边界见同级API仓库 `src/modules/ai/README.md`。真实调用默认不启用；配置密钥及独立只读账号后再由用户在页面同意本次数据外发。此版本不提供正式写入。
