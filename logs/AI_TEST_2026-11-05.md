## 启动

```powershell
# API目录
npm run ai:sandbox

# Web目录，另开终端
$env:VITE_API_BASE_URL='http://127.0.0.1:8866'
npm run dev -- --host 127.0.0.1 --port 5176 --strictPort
```

访问 `http://127.0.0.1:5176/ai`。停止后移除本终端环境覆盖再恢复普通联调。

真实配置和数据边界见同级API仓库 `src/modules/ai/README.md`。真实调用默认不启用；配置密钥及独立只读账号后再由用户在页面同意本次数据外发。此版本不提供正式写入。
