# 公开分享 API

> **更新日期**: 2026-06-30

提供日记/动态的公开分享功能，支持 Token 模式和密码模式两种访问方式，免登录即可查看。

## 接口列表

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/share/:token` | 无 | Token 模式公开查看（白名单放行） |
| POST | `/share/password` | 无 | 密码模式公开查看 |

---

## 接口详情

### 1. Token 模式查看

**路径**：`GET /api/v1/share/:token`

**鉴权**：无（`securityCheck` 白名单放行）。

**说明**：通过分享链接中的加密 Token 直接查看日记内容，无需登录。

**Token 校验流程**：
1. 调用 `verifyShareToken(token)` 解密并验证 Token
2. 检查 Token 是否过期（`exp` 字段）
3. 根据 `did`（日记 ID）查找日记
4. 校验 `visible_type` 中的 `vt`（可见类型）、`vs`（批次号）、`pw`（密码熵）
5. 任一项不匹配即返回错误

**响应**：
```json
{
  "status": 200,
  "data": {
    "id": "xxx",
    "content": "日记内容...",
    "img_url": ["url1", "url2"],
    "mood": "开心",
    "location": {"name": "深圳"},
    "create_time": "2026-06-30 21:00:00",
    "author": {"name": "小明"},
    "expire_at": "2026-07-07T21:00:00.000Z"
  }
}
```

**错误状态码**：

| status | 含义 |
|--------|------|
| 400 | Token 无效或已损坏 |
| 403 | 分享已关闭、链接失效、或密码不对 |
| 404 | 内容不存在或已删除 |
| 410 | 分享链接已过期 |

---

### 2. 密码模式查看

**路径**：`POST /api/v1/share/password`

**鉴权**：无（`securityCheck` 白名单放行）。

**说明**：通过日记 ID + 6 位数字密码验证后查看。

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 日记 ID |
| `pw` | string | ✅ | 6 位数字密码 |

**防暴力破解机制**（内存滑动窗口）：

| 参数 | 值 | 说明 |
|------|------|------|
| 最大尝试次数 | 5 次 | 每个窗口内最多尝试次数 |
| 滑动窗口 | 60 秒 | 超过后窗口重置 |
| 锁定时间 | 120 秒 | 超限后锁定 |
| 追踪键 | `IP:日记ID` | 按 IP + 日记 ID 组合追踪 |

**密码错误响应**：
```json
{
  "status": 403,
  "message": "密码错误，还剩 4 次机会"
}
```

**超限锁定响应**：
```json
{
  "status": 429,
  "message": "尝试次数过多，请 120 秒后再试",
  "retryAfter": 120
}
```

**说明**：内存存储，服务重启后追踪记录自动清空。Map 超过 500 条时自动清理过期条目。

## 安全说明

1. **免登录访问**：两个接口均配置在 `securityCheck` 白名单中，不经过安全头校验
2. **Token 校验**：多层校验（过期、可见性、批次号、密码熵），任一不通过即拒绝
3. **密码防爆**：滑动窗口 + IP 绑定，防止恶意枚举密码
4. **软删除保护**：已删除的日记通过分享链接也无法访问
