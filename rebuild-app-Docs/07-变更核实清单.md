### 对应 web 契约
- web 调用：`web/src/utils/api/auth.js` → `POST /auth/login` body `{ nameOrEmail, password }`。
- 后端：`api/src/modules/auth/`（controller/api）：password 传明文即可，resolvePassword 原样放行；成功信封 token 在顶层。
- 原生传输沿用 AES 信封（ApiClient + HandshakeManager），**未做 web 那套 RSA 逐字符加密**（留作后续增强；AES 信封已保证传输加密）。
